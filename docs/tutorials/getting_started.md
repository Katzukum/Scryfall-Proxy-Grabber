# Getting Started with ProxyToolBox

This tutorial will guide you through the process of printing your first batch of MTG proxy cards using ProxyToolBox.

## 1. Preparing Your Card List

First, prepare a deck list in [Moxfield export format](https://www.moxfield.com/). Your list should look like this:

```
1 Venser, the Sojourner (SOM) 135
4 Lightning Bolt (M11) 149
```

## 2. Downloading the Cards

1. Open ProxyToolBox.
2. Provide a name for your "Proxy Order" (this will be the folder where cards are saved).
3. Paste the card list into the downloader tab text area.
4. If you also need token cards, enable the **Include tokens** checkbox.
5. If you want double-sided token layouts, configure that option as well.
6. Click **Start Download**.

Wait for the download to finish. Card images will be saved inside the `order_name` folder under `My_Proxy_Order`.

## 3. Creating the Print Setup sheets

1. Navigate to the **Print Setup** tab.
2. Browse your file system and point the app to the newly created folder containing your downloaded images.
3. Configure the output format (PDF or PNG).
4. If you chose to print double-sided cards directly from Scryfall images downloaded as Transformers, make sure to check "Transformer".

Your print sheets are ready inside the chosen folder.
