# ProxyToolBox Documentation

Welcome to the documentation for ProxyToolBox.

ProxyToolBox is a desktop application for downloading, laying out, and printing MTG proxy cards. It uses a Python backend and a web frontend.

## Components

- **Downloader**: Fetches cards using the Scryfall API.
- **Print Setup**: Arranges downloaded cards onto PDF or PNG sheets for printing.
- **Card Lookup**: Fuzzy and exact card searching via Scryfall.
- **Frontend**: A React/Vite web application communicating with the backend via Pywebview.
